# Engineering Notes

## RAG

Retrieval-Augmented Generation (RAG) retrieves relevant
information from an external knowledge source and supplies
it to a language model to help answer a question.

## LangGraph

LangGraph helps build stateful workflows with nodes,
edges, conditional routing, and cycles.

## Evaluation

RAG systems should be evaluated for retrieval quality,
answer relevance, faithfulness, latency, and cost.
